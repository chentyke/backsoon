# BackSoon 品牌指南

[English](README.md)

![BackSoon 分享图](social.png)

一块稍微歪着的门牌，是店主离开时留下的「稍后回来」。牌面上镂空的回转箭头借自键盘上的回车键，指向任务发起的那条聊天。门牌挂在一颗黄色圆钉上，逆时针倾斜 6°，字标保持水平。

## 名字和文字

产品名写作 **BackSoon**，中间的 S 大写。终端命令、npm 包名和 Skill 名统一写作 `backsoon`。中文介绍可以直接说「让命令在后台跑，结果回到原来的聊天」。英文短介绍用 **Background tasks for Codex**。

任务状态写实际发生的事，例如「编译已完成」「退出码 1」「已加入聊天队列」。一次任务可能运行成功、通知却发送失败，界面要让人能分别读出这两个结果。

## 标志

图标画在 64 单位的网格上。门牌是 7 单位的平滑圆角，圆钉半径 4.6 单位，带一点柔和的高光。粗 3 单位的墨蓝挂绳穿过门牌上的两个孔眼，深色背景上挂绳改用纸白。箭头和孔眼都是镂空的，任何尺寸下都会露出背后的底色。单色图标去掉孔眼，因为同色的挂绳会和门牌融在一起。不要把箭头填色，不要给门牌加描边，也不要把门牌摆正。

| 用在哪里 | 素材 | 用法 |
| --- | --- | --- |
| 文档标题、面板页头 | [浅底组合标志](logo.svg)、[深底组合标志](logo-dark.svg) | 图形在左，字标在右。建议宽度至少 112 px。 |
| 浏览器标签页、小图标 | [浅底图标](mark.svg)、[深底图标](mark-dark.svg) | 直接使用方形画布，最小 16 px。 |
| 单色印刷 | [单色矢量图标](mark-mono.svg) | 跟随当前文字颜色，箭头镂空。 |
| 项目头像 | [512 × 512 PNG](avatar.png) | 已留出适合圆形裁切的空间。 |
| GitHub 仓库和社交分享 | [1280 × 640 PNG](social.png)、[可编辑 SVG](social.svg) | 按原比例使用。 |

组合标志四周至少留出一个大写 B 半高的空白。图标独立使用时保留原来的四边留白。

## 色彩

| 颜色 | 色值 | 用途 |
| --- | --- | --- |
| 群青 | `#344BE4` | 浅底上的门牌、分享图背景 |

## 面板

面板沿用同一套颜色，用柔和的卡片来组织。浅色主题是 `#F4F4F5` 底色上的白色卡片，深色主题是 `#0E0E10` 底色上的 `#1C1C1F` 卡片。卡片不加边框，靠两层柔和阴影浮起。任务行圆角 16 px，任务窗口圆角 28 px。

每种情况只用一种颜色：运行中用蓝色，等待或需要处理用黄色，完成用绿色，失败用红色，中断用橙色，已确认完成用青色，已停止用灰色。颜色总是和状态文字一起出现。

动效使用弹簧曲线。任务窗口从所在的那一行展开，关闭时收回原处。变化的文字带着轻微模糊淡入，任务完成时对勾会弹一下。系统开启“减少动态效果”时全部跳过。

## 字体

字标取自 [Bricolage Grotesque](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque)，已转成矢量轮廓，使用时无需安装字体。面板优先使用系统圆体，没有时使用系统界面字体。命令、耗时和日志使用等宽字体。分享图里的任务行使用系统字体的可编辑文字。
